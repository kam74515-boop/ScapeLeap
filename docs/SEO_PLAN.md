# ScapeLeap SEO plan

## Search positioning

ScapeLeap targets interior design studios that need a connected operating
system rather than a generic task manager. Chinese is the default unprefixed
locale and English uses `/en`.

## Core topic clusters

1. Interior design studio management
2. Interior design project management and seven-stage delivery
3. FF&E Schedule, sourcing, procurement and change tracking
4. Design fees, proposals, contracts and client payments
5. AI moodboards, material exploration and project-aware generation
6. Client portals, approvals and design collaboration

## Indexing rules

- Index marketing, solution, resource, documentation and company pages.
- Do not index authentication, onboarding, application, portal, admin or API
  routes.
- Every public page declares a canonical and Chinese/English alternates.
- The home page emits Organization, WebSite and SoftwareApplication JSON-LD.
- Add Article, TechArticle and Breadcrumb JSON-LD when real editorial content
  is published.

## Content roadmap

- Publish studio operating guides before broad AI trend content.
- Build one pillar guide for each topic cluster, then connect supporting
  articles to the relevant product or solution page.
- Create reusable templates for project briefs, stage gates, FF&E schedules,
  design fee proposals, change orders and client handover checklists.
- Use anonymized customer stories only after real outcomes and permission are
  available; do not fabricate testimonials or usage statistics.
